# 🚀 TrackHire

### Organize your job search, one application at a time.

TrackHire is a MERN Stack job application tracker built to help users manage their job search — track applications, visualize progress on a Kanban board, and stay organized from "Applied" to "Offer."

This project is being built in public, feature by feature, as part of my journey to become a full-stack developer — with a focus on clean component structure, reusable UI patterns, and eventually a fully connected REST API backend.

## 📌 About This Project

TrackHire aims to solve a real problem: job seekers often lose track of applications across spreadsheets, emails, and notes apps. This project brings everything into one place — a single dashboard to track every application's status, notes, and progress.

It's also a personal learning project — I'm building it end-to-end (frontend → backend → deployment) to apply and deepen what I've learned in React, Node.js, and MongoDB.
