# Job Application Tracker

## Project Overview

A MERN Stack web application that helps users manage and track job applications.

---

## Features

- User Authentication
- Dashboard
- Job CRUD
- Kanban Board
- Search & Filter
- Responsive Design

---

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB

---

## Installation

```bash
npm install
npm run dev
```
