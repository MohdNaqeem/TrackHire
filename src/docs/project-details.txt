12. Authentication flow:

Register
   ↓
password hashed
   ↓
User saved


Login
   ↓
email/password verified
   ↓
JWT created
   ↓
cookie/token
   ↓
React knows user is authenticated

Then:
GET /api/applications
        ↓
auth middleware
        ↓
verify JWT
        ↓
get userId
        ↓
find applications belonging to user
        ↓
return applications
